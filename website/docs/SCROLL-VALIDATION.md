## 复现与修复

相同的三次半屏滚动，修复前位置为 `1056 → 1056 → 1056px`；修复后为 `360 → 720 → 1080px`。先前“每次手势只切一段”的测试验证了错误目标，已删除。阅读停留改由桌面 720svh、窄屏 680svh 的轨道安排，正文与镜头、灯光、标签仍保持同一渲染进度。

## 诊断与范围

`?scroll-debug=1` 显式开启中文滚动日志和实时渲染指标；正常页面不加载诊断面板，日志不上传。计数与采样比单张静止截图更能反映本次故障，但不保证所有设备的帧率。

手机为浏览器视口模拟，未做手机实机触摸测试。站点外部 GitHub 页面及模型服务不属于本次网页滚动回归。
