通过临时测量页在同一浏览器加载原页面和资源，仅附加 PerformanceObserver 与 120 帧计时。测量页已移除，发布检查会阻止其残留。

测试条件：当前 Mac、内置浏览器、localhost、未进行网络或 CPU 限速、热缓存；不是手机真机或公网真实用户数据。

| 样本 | LCP | CLS | 帧间隔中位数 | 帧间隔 P95 |

| 桌面 1440px | 76 ms | 0 | 8.3 ms | 8.8 ms |
| 手机视口 390px | 92 ms | 0 | 8.3 ms | 9.2 ms |

阶段按钮交互事件耗时观测到桌面 40 ms、手机视口 48 ms。它是本次交互的实验室样本，不等同于线上 INP 分位指标。手机首屏复测没有触发交互，因此该次记录的 interaction 字段为空。

这些观测满足本机样本中的性能目标，不能推断所有设备的 LCP / INP。未完成的扩展验证包括低端 Android、物理 iPhone、其他浏览器、弱网及线上真实用户指标。
