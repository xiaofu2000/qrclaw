# 官网重设计验收记录

日期：2026-10-20（Asia/Shanghai）。本记录覆盖当前 Q 形分层装置与四段滚动镜头，替代首版验收中的视觉、阶段和性能结论。

## 实现范围

- 官网源码、素材与文档位于 `website/`。产品客户端、后端和现有运行服务未因本次重设计修改。
- 三维主体为程序生成的 Q 形装置，包含任务层、工具层、记忆层及与模型坐标同步的标签；滚动控制部件展开、镜头与四段文字。
- 固定导航、真实工作台截图衔接、任务回放、记忆节点、Web / CLI / API 标签、安装命令和 FAQ 均保留。
- 场景在窄屏改为上下构图。暂停与系统减少动态效果采用静态关键帧，滚动仍会切换内容；WebGL 不可用时保留静态说明与行动入口。
- 展示字体为自托管 Satoshi 与 Noto Sans SC 中文标题子集。免费 MIT 相机示例的插值思路及函数改编、字体许可、真实产品图片的来源见 `SOURCES.md`。

## 浏览器证据

在当前 Mac 的 ChatGPT 内置浏览器中检查 360、390、677、768、1440 CSS 像素宽度。未发现页面横向溢出或已加载的破图。最终七项布局修复在 390、677、768、1440 的 12 张截图中核对；360 宽度在最终源码下再次检查，页面宽度为 351px，差值来自滚动条。

已实际操作：

- 四个阶段按钮及滚动镜头；拆解和执行状态出现对应层标签，最终阶段衔接真实产品画面。
- 暂停后继续滚动，内容和静态关键帧同步变化。
- 任务回放切换到执行与交付；标签方向键切换；记忆节点更新对应说明。
- 手机导航展开、选择导航项后收起；API 入口更新代码；复制操作显示成功反馈。
- 减少动态效果与 WebGL 不可用的临时测试页。减少效果时控件禁用，手动选阶段仍更新内容；无 WebGL 时显示替代内容。

正常页面控制台未观察到警告或错误。系统剪贴板实际内容未验证，复制成功提示只证明页面调用成功。

## 构建与审阅

执行 `npm test`、`npm run check`、`npm run build`。六项状态与滚动插值测试通过，资源、锚点、控件目标和发布目录检查通过，Three.js 模块构建成功。

发布栅格素材共五个，来源扫描零遗漏。分享图已更新为新首屏。

独立设计初审发现七项问题：部件角色、模型遮挡、固定导航、窄屏示意标识、中文展示字体、字符图标、减少动态效果的无障碍名称。修复后七项均被复判为 resolved，结论为 ship；范围仅覆盖这些修复及截图回归，不能替代所有设备上的连续动画验证。详见 `REVIEW.md`。

## 最终性能样本

测试环境为同一台 Mac、内置浏览器、localhost、热缓存，无 CPU 或网络限速。临时测量页附加 PerformanceObserver 和 120 帧计时，并点击拆解阶段；测量页已移除，发布检查会阻止其残留。

| 视口 | LCP | CLS | 交互事件耗时 | 帧间隔中位数 | 帧间隔 P95 |
| --- | --- | --- | --- | --- | --- |
| 1440 × 900 | 172 ms | 0.0000471 | 32 ms | 8.3 ms | 9.2 ms |
| 390 × 844 | 124 ms | 0.0261653 | 40 ms | 8.3 ms | 9.3 ms |

这里的交互耗时是一次实验室观测，不是线上 INP 分位值。窄屏样本来自桌面浏览器调整视口，不是物理手机；数值不能推断公网或低端设备性能。

## 交付边界

- 这是静态官网及交互演示，不在公网执行访客的 Agent 任务。
- 真实产品证据和安装验证沿用 `demo-evidence.md` 与首版记录，不声称本轮重新运行了模型或重新安装产品。
- 尚未验证物理 iPhone、低端 Android、其他浏览器、弱网和线上真实用户指标。
- Sites 继续使用既有站点与私有访问范围。本轮发布终态凭据保存在本机 `.local/deployment-redesign.json`；以该结果为准，本文不预先声称部署成功。
