# QRClaw Web UI

此目录是 QRClaw 的 React/Vite 前端。先在项目根目录运行 `uv run qrclaw serve`，再运行：

```bash
npm ci
npm run dev
```

开发服务器将 `/api` 请求代理到 `http://127.0.0.1:8765`。也可以在项目根目录执行 `./start_ui.sh` 同时启动两者。

检查前端：`npm run lint`、`npm run build`。

工作区小精灵使用 [bloub](https://github.com/jeremy-prt/bloub) 的 SVG 动画引擎，依据当前会话的真实状态显示：等待（小点）、思考（三点）、工具执行（轨道）、子任务（粒子）、回复（睁眼）、上下文压缩（彗星）、完成（通知点）、异常（感叹号）。当前会话空闲时会提示其他会话的后台任务。减少动态效果时显示代表帧，页面隐藏时暂停动画。

状态映射位于 `useChatWorkspace.ts`，React 视图为 `AgentSprite.tsx`；引擎版本与许可见 `src/vendor/bloub/README.md`。代码使用 MIT 许可，上游角色形象的设计权利不包含在代码许可中。

界面采用蓝灰导航、白色工作面和钴蓝操作色。桌面伙伴以 104px 悬浮卡片在聊天页默认显示于工作面左上角，记忆页显示于右上角，切换页面时自动重置位置，状态文案保留在顶栏；卡片支持拖动、方向键移动和 Home 键回到当前页面的默认角落。手机保持大尺寸欢迎伙伴与工作时的顶栏伙伴，始终只挂载一个动画实例。手机使用独立导航与执行抽屉。

记忆页使用紧凑工具栏，错误提示、任务记录与检查报告共享总高度受限的辅助滚动区，任务默认收起，报告首次出现时展开且可收起。大于 1000px 的窗口让列表与详情独立滚动；较窄窗口从列表进入单栏详情，返回时保留搜索条件、编辑草稿和滚动位置，焦点回到当前条目或搜索框。视觉约定见项目根目录 `DESIGN.md`，产品边界见 `PRODUCT.md`。
